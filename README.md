
# React + Vite
Voice-based Mock Interview Platform

This template provides a minimal setup to get React working in Vite.
A web application that simulates a real interview experience using voice interaction. The system acts as the interviewer, asks questions, listens to the candidate’s responses, and provides feedback based on the conversation.


______________________________________________________________________________________________________________________________________________________________________________________________________________________

AI-powered interviewer that asks questions via voice.

Candidates respond using speech recognition.

Follows up with relevant questions based on candidate answers.

Handles natural pauses and inactivity.

Timer-based interview (e.g., 15 minutes).

Generates AI feedback and scores at the end of the session.

Minimal, clean, user-friendly UI.
______________________________________________________________________________________________________________________________________________________________________________________________________________________
Tech Stack

Frontend: React.js

AI: OpenAI API (Chat Completions)

Speech Recognition & Text-to-Speech: Web Speech API

Routing: React Router

Styling: CSS
______________________________________________________________________________________________________________________________________________________________________________________________________________________

Features

Start Screen

Google login integration (optional).

Welcome message and “Start Interview” button.
______________________________________________________________________________________________________________________________________________________________________________________________________________________
Interview Flow

System asks first question: “Tell me about yourself.”

Candidate responds via voice.

AI asks follow-up questions dynamically.

Continues until time runs out or candidate is inactive.

Handles natural thinking pauses (e.g., 10–12 seconds).

End of Session

AI generates feedback and assigns a score.

Displays feedback on a separate screen.

______________________________________________________________________________________________________________________________________________________________________________________________________________________

Clean interface with timer, conversation history, and control buttons.

Buttons: Speak Answer, End Interview.
